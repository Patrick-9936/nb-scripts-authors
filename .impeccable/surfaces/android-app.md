# Android application

Mode: operate

Audience: Null's Brawl players browsing, managing, and launching community scripts on a phone.

Task: keep the catalog and cached account useful immediately, then move from a script card to battle launch with minimal waiting.

Constraints: preserve all existing functions, themes, localization, package identity, and Android-native navigation; support dense lists and large code files.

## Direction contract

THESIS: Script Library becomes a calm, tactile library of translucent layers; it refuses the noisy gamer dashboard and the flat stack of unrelated white cards.

OWN-WORLD: Android-native structure with iOS 26-inspired Liquid Glass: ink-blue and violet accents, translucent controls and surfaces, animated background light, crisp one-pixel highlights, 16–30 dp radii, system typography, and blur where one layer visibly floats above another.

STORY: Cached scripts and account identity appear immediately. Fresh data replaces them quietly. Script details lead to a single fast battle sheet, and every failure offers a clear recovery action inside the same visual language.

FIRST VIEWPORT: A compact top app bar, dense searchable library, and translucent four-destination navigation frame the screen. Script cards remain the largest content area. Detail and battle flows rise as draggable bottom sheets with a visible handle and pinned primary action.
