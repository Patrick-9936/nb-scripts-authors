# Безопасность

## Модель доверия

Script Library — независимый клиент сервиса `scripting.nulls.gg`. У приложения
нет собственных привилегий: оно не может выдавать релизы, менять список авторов
или видеть чужие аккаунты. Всё, что клиент делает от имени пользователя,
сервер Null's проверяет заново по его сессии.

Из этого следует главное: **подмена клиента не даёт доступа к чужому аккаунту**.
Пропатченное приложение может только выдать себя за самого пользователя, у
которого уже есть эта сессия.

## Что где проверяется

| Действие | Кто проверяет |
| --- | --- |
| Просмотр и скачивание кода скрипта | API Null's по сессии пользователя |
| Публикация, правка и удаление скриптов | API Null's по сессии пользователя |
| Запуск боя | API Null's: токен выдаётся только для подтверждённого автора |
| Список авторов | Файл `list.txt` в ветке `android-script-library` |
| Доступ к статистике | Сервер: `library_permissions` плюс список `OWNER_UUIDS` |
| Синхронизация настроек | Сервер: сессия проверяется через `/users/me` |
| Установка обновления | Android: подпись APK сверяется с установленным приложением |

## Что закрыто в клиенте

- Сессия не берётся из cookie для стороннего origin. Встроенный WebView игры
  присылает `Origin: null` и обязан передать токен в заголовке
  `x-script-library-session`; страница на чужом домене не может «оседлать»
  чужую сессию.
- CORS-заголовки отдаются только для известных origin. Произвольный origin
  больше не получает `access-control-allow-origin`.
- Ответы API идут с `x-content-type-options: nosniff` и `referrer-policy`.
- Телеметрия принимается только с корректным UUID установки, известной
  платформой и версией вида `1.7.24`; повтор в пределах десяти минут не
  пересылается, а сервер ограничивает число новых установок на аккаунт в сутки.
- Обновление проверяется по SHA-256 из GitHub и по сертификату подписи:
  APK с другой подписью не доходит до установщика.
- Пароли хранятся только при явном «Запомнить вход» и шифруются ключом
  Android Keystore. Очистка данных удаляет и сессию, и кэш каталога.
- `allowBackup` выключен, резервные копии не выносят сессию с устройства.
- Обмен с сервисом идёт только по HTTPS (`usesCleartextTraffic="false"`).

## Что закрыто в репозитории

- Список авторов меняется только через workflow `Manage authors`, который
  требует прав на запись в репозиторий. Токенов в приложении и на сайте нет.
- Тег релиза проверяется по формату `vX.Y.Z`, поэтому значение из
  `workflow_dispatch` не попадает в путь к файлу заметок.
- Права workflow сужены: чтение на уровне файла, запись — только у job сборки.
- Проверка контракта API (`API contract check`) следит за молчаливыми
  изменениями схемы и открывает issue, если сервис поменял поля.

## Что остаётся вне контроля

- Скомпрометированный аккаунт Null's: сессия даёт те же права, что и вход в
  браузере. Смена пароля и выход завершают её.
- Подписанный мод для игры: подпись выдаёт сообщество, проверить её в CI нельзя.
- Устройство с root: Android Keystore защищает ключ, но не мешает читать
  память процесса.
